# TripEasy

TripEasy is a responsive group travel-planning web application.

A trip leader can create a trip, add activities and invite other travellers. Members can view the shared itinerary, respond to activities and track estimated costs.

## Planned Technologies

- React
- Python
- FastAPI
- PostgreSQL
- Pytest
- Docker
- GitHub Actions
- Microsoft Azure
